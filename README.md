# Дисциплина — трекер привычек

Минималистичный трекер привычек в кремово-коричневой «дорогой» палитре.
Expo (SDK 54) + React Native + TypeScript, локально-first: данные хранятся
только на устройстве, аккаунт не нужен.

## Запуск

```bash
npm install
npx expo start
```

Отсканируй QR-код из терминала приложением **Expo Go** (Android/iOS) —
и приложение откроется на телефоне.

## Что уже есть (v0.3)

- **Сегодня** — кольцо дня (прогресс по всем привычкам), карточки по времени
  суток (утро/день/вечер/любое время), быстрая отметка и «+1» прямо с карточки.
- **Привычки 4 типов** — галочка, количество, время (минуты), своя единица
  (страницы, км, литры…). У каждой: цель на день, дни недели, время суток,
  дедлайн и окно начала («с 18:00 до 21:00»), цвет и «зачем я это делаю».
- **Календарь** — сетка месяца, под датами точки цветов привычек (всё
  выполнено — зелёная точка). Тап по дате → плавная шторка со списком дел →
  тап по делу → большая шторка с характеристиками, прогрессом и удалением.
- **Редактирование** — измени любую привычку через кнопку с карандашом,
  история сохраняется.
- **Напоминания** — локальные push в дни привычки в выбранное время,
  работают при закрытом приложении (нужны разрешённые уведомления).
- **Заморозка серии** — страховка как в Duolingo: пропущенный день можно
  заморозить (1 заморозка на 7 дней), серия не сломается.
- **Статистика** — тепловая карта года в стиле GitHub (тап по дню открывает
  шторку с делами), итоги за 30 дней, карточки по привычкам: серия,
  % за месяц, мини-график за 14 дней.
- **Профиль** — статистика месяца, лучшая серия, статус уведомлений, сброс данных.

## Стек

| Задача | Инструмент |
|---|---|
| Каркас | Expo SDK 54, expo-router (файловые маршруты) |
| Состояние | zustand + persist (AsyncStorage) |
| Анимации | reanimated 4 + react-native-gesture-handler |
| Графика кольца | react-native-svg |
| Отклик | expo-haptics (вибрация на отметках) |
| Шрифты | Yeseva One (заголовки) + Manrope (интерфейс) |

## Структура

```
src/
  app/            — экраны и маршруты (expo-router)
    (tabs)/       — Сегодня, Календарь, Статистика, Профиль
  components/     — Sheet (плавная шторка), DayRing, HabitCard, формы
  store/          — zustand-стор привычек и выполнения
  lib/            — работа с датами, селекторы (серии, просрочки, статистика)
  theme/          — палитра, шрифты, отступы
  types/          — модели данных
```

## Дорожная карта

- **Фаза 4** — XP и уровни, челленджи (21/30/90 дней), онбординг, тёмная тема
- **Фаза 5** — таймер внутри приложения, экспорт данных, виджеты, синхронизация

Примечание: напоминания зависят от системы — в Expo Go они работают с
ограничениями на некоторых устройствах; в отдельной сборке (dev-build / стор)
работают полностью. Проект настроен на Expo SDK 54 (совместим с Expo Go
из App Store).
